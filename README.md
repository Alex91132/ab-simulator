# Симулятор A/B-тестов

Интерактивный инструмент для портфолио: калькулятор размера выборки,
визуализация статистической мощности и Монте-Карло симуляция тысяч
экспериментов. Один самодостаточный файл, чистый HTML + JavaScript,
без единой библиотеки.

**Живая страница (после публикации):** https://alex91132.github.io/ab-simulator/

---

## Что внутри

| Блок | Что делает |
|---|---|
| **1. Калькулятор** | Размер выборки для z-теста двух долей: базовая конверсия, MDE (относительный/абсолютный), α, мощность, одно-/двусторонний критерий, оценка длительности теста по трафику. Формулу можно раскрыть с подставленными числами. |
| **2. Мощность — глазами** | Распределения оценки эффекта при H₀ и H₁ с раскрашенными зонами: α (ложные победы), β (пропущенный эффект), мощность. Пересчитывается на лету при движении ползунков. |
| **3. Монте-Карло** | До 10 000 симулированных экспериментов с любым «истинным эффектом». Показывает долю значимых, «проклятие победителя» (завышение лифта среди значимых), долю побед с обратным знаком, гистограммы измеренного лифта и p-value. |
| **Принципы** | Формулы, допущения и честные ограничения (фиксированный горизонт, нет поправок на подглядывания и множественные сравнения). |

Дополнительно: тёмная тема (как на всём сайте), состояние в URL
(ссылкой можно поделиться — например, с уже выставленным «нулевым эффектом»),
мобильная вёрстка.

## Файлы

- `index.html` — вся страница: разметка, стили (страничные), логика.
- `reference_check.py` — эталонная проверка статистики на Python (см. ниже).
  На сайт не обязателен, нужен для самопроверки.

Страница подключает общий `styles.css` сайта (`../styles.css`) и ведёт себя
как остальные страницы: та же шапка, шрифты, цвета, переключатель темы
(`localStorage` + `prefers-color-scheme`).

## Запуск

Проект самодостаточен: один `index.html` без сборки и зависимостей —
просто откройте его в браузере или перейдите на
[живую страницу](https://alex91132.github.io/ab-simulator/).
Для сверки расчётов с эталонами: `python reference_check.py`.

## Методология и проверка

Модель: конверсия (доля), сплит 50/50, z-тест с объединённой дисперсией;
размер выборки — стандартная формула с нормальной аппроксимацией
(та же, что у Evan Miller / книги Kohavi et al.).

`reference_check.py` считает эталонные значения и Монте-Карло на Python
и совпадает со страницей один в один:

| Проверка | Эталон (Python) | Страница |
|---|---|---|
| n на вариант: 10% → 11%, α=5%, мощность 80%, двусторонний | 14 751 | 14 751 |
| то же, односторонний | 11 620 | 11 620 |
| Монте-Карло, истинный эффект = MDE | 80,2% значимых | 80,5% |
| Монте-Карло, истинный эффект = 0 | 5,1% значимых (α=5%) | 5,0% |
| Средний лифт среди значимых при эффекте = MDE | +1,12 п.п. | +1,13 п.п. |

Запуск проверки: `python reference_check.py` (только стандартная библиотека).

## Идеи развития

- Метрика-среднее (непрерывная), не только доля.
- Демо «подглядывания» (sequential peeking): остановка при первом
  p < 0,05 раздувает α — эффектный урок на том же движке.
- Поправка на множественные сравнения (Бонферрони) для A/B/n-тестов.
- Экспорт результатов симуляции в CSV.
